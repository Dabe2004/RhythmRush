# Rhythm Rush frontend

React + Vite + Tailwind CSS v4. See `../docs/FRONTEND.md` for how to run the
dev server, the page list, and the manual test checklist.

```powershell
npm install
npm run dev
npm run build
npm run lint
npm test
```

For the exhibition you do not need `npm run dev`: run `npm run build`, then
`npm start` in the project root serves the website from the backend.
